# Image Encryption Tool 

## About the Project
This is a simple image encryption tool built using Python.
It encrypts and decrypts images using XOR pixel manipulation.
This project was made as Task 02 of my SkillCraft Technology Internship.

## How it Works
Every image is made of pixels.
Each pixel has a number value (0 to 255).
We apply XOR operation on each pixel using a secret key.
Same key is used to decrypt the image back to original!

## Technologies Used
- Python 3
- Pillow (PIL) - to open and save images
- NumPy - to work with pixel values

## How to Run
1. Install libraries:
   pip install pillow numpy

2. Run the script:
   py image_encryption.py

3. Enter your choice (encrypt/decrypt)
4. Enter image file name
5. Enter a secret key number
